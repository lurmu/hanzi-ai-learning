# 学习数据
这个目录存放汉字学习数据

## 汉字库格式

```json
{
  "id": "hanzi-001",
  "character": "一",
  "pinyin": "yī",
  "english": "one",
  "radical": "一",
  "strokes": 1,
  "difficulty_level": 1,
  "grade_level": "kindergarten",
  "audio_url": "/audio/yi.mp3",
  "stroke_order_url": "/images/yi_stroke_order.gif",
  "frequency": 1.0
}
```

## 文件说明

- `hanzi.json` - 1200+个汉字库（需要单独准备）
- `curriculum.json` - 课程大纲
- `assets/` - 音频、图片等资源
